# 项目适配指南

本指南回答两个问题：**这个脚手架适合做什么类型的项目**，以及**做不同类型项目时要注意什么**。

## 一、一句话定位

这是一个 **「本地优先、桌面优先、Web 可用」的应用发射台**。它预置了 SQLite / IndexedDB 领域数据层、系统托盘、自动更新、跨平台 CI 与可选同步接缝，把常见样板代码做完，让你只专注业务功能。

> 适合 vibe coding：描述需求 → AI 写 Vue 组件 + 少量 Rust/SQL → `tauri dev` 看效果 → 配置项目自己的更新端点与签名并通过严格 release gate 后，再打 tag 创建三端 draft release。

## 二、最适合的项目类型（强烈推荐）

| 类型 | 典型例子 | 为什么契合 |
|---|---|---|
| 个人知识 / 生产力 | 笔记、待办、日记、习惯追踪、时间追踪 | SQLite 离线存储、隐私好、托盘常驻体验顺 |
| 隐私 / 个人数据 | 记账、消费追踪、密码箱 | 数据不出本机是核心卖点，可再加加密层 |
| 开发者实用工具 | API 客户端、DB 查看器、日志查看器、JSON/YAML 格式化 | 开发者即用户，托盘常驻 + 直接读文件系统 |
| AI 桌面客户端 | 网页 Chat 套壳、本地 LLM 前端、RAG 知识库 | 对话历史存本地 SQLite，Rust 侧可接本地模型 |
| 媒体 / 文件管理 | 本地图库、电子书管理、下载管理器、去重 | 扫文件系统 + 本地索引，Rust 比 Node 顺手 |
| 自托管面板 | Home Lab / NAS 控制台、自建服务面板 | 本质是「带本地配置 + 自动更新」的前端壳 |

## 三、可行但有前提的项目

| 类型 | 前提 / 代价 |
|---|---|
| 多人协作 / 实时同步 | 壳是本地优先，需自己接后端或用云同步，这部分壳帮不了你 |
| 像素级一致 UI | 三端用不同 WebView（WebView2 / WKWebView / WebKitGTK），CSS 滤镜、滚动条、字体有细微差异，别承诺 100% 一致 |
| 重度 Node 原生生态 | 大量原生 npm 依赖时，Electron 反而更省事，硬上 Tauri 会反复重写轮子 |

## 四、不建议用这个壳的项目

- **纯网站 / Web App** —— 用 Vite 就够了，无需 Tauri。
- **图形密集型游戏 / 3D** —— 性能与工具链不匹配。
- **从成熟 Electron 项目迁移** —— 除非有硬理由（体积、性能、移动端）。
- **系统级深度集成** —— 虚拟摄像头、内核扩展等超出 Tauri 能力边界。

## 五、从模板开始做第一个应用

选好项目类型后，不要直接把演示页改成大而全的产品。先读 [blueprints/README.md](./blueprints/README.md)，在本地笔记库、开发者本地工具和本地 AI 伴侣三条窄路径中选一条。每条都说明了首个用户旅程、起始文件、平台降级、安全边界和验证命令。

## 六、分类型开发注意事项

### 5.1 个人知识 / 生产力工具
- **迁移先行**：在 `src-tauri/src/db.rs` 里定义好表结构，用 `add_migrations` 管理版本，避免后续改表引发兼容问题。
- **全文搜索**：数据量大时，接 `tauri-plugin-sql` 的 FTS5，或用 Rust 侧 `tantivy`/`sqlite` 扩展，别在前端内存里扫。
- **托盘体验**：关闭按钮建议「隐藏而非退出」（模板已默认），让工具常驻后台。

### 5.2 隐私 / 个人数据类
- **加密**：SQLite 落盘是明文，敏感数据（密码、密钥）用 `sqlcipher` 或应用层加密（如 `keyring` 存主密钥）。
- **备份导出**：Todo 示例已提供版本化 JSON 数据端口；产品 UI 仍需让用户确认追加导入语义，并按产品数据模型扩展，避免把密钥或原始数据库文件导出。
- **identifier 不可改**：发布前定好 `tauri.conf.json` 的 `identifier`，改掉会导致老用户收不到更新。

### 5.3 开发者实用工具
- **文件访问**：走 `tauri-plugin-dialog` + `tauri-plugin-fs`，在 capabilities 里按需开权限，不要一把全开。
- **命令执行**：`tauri-plugin-shell` 需谨慎，校验输入避免命令注入。
- **托盘常驻**：这类工具最吃「托盘常驻 + 全局快捷键」，可加 `tauri-plugin-global-shortcut`。

### 5.4 AI 桌面客户端
- **流式响应**：用 `@tauri-apps/api/event` 或自定义 command 做流式，别阻塞主进程。
- **本地模型**：Rust 侧接 `llama.cpp` / `candle`，注意模型体积与冷启动（首次加载慢）。
- **对话历史**：SQLite 存会话，记得建索引（会话 id、时间）。

### 5.5 媒体 / 文件管理
- **索引**：大量文件时用 Rust 侧并发扫描 + 本地索引，别在前端同步遍历。
- **缩略图**：生成缩略图缓存到本地目录，避免每次重算。

### 5.6 自托管面板
- **更新端点**：`plugins.updater.endpoints` 指到你自己的静态服务器或 GitHub Releases。
- **签名密钥**：私钥放 CI secret（模板已配好 `TAURI_SIGNING_PRIVATE_KEY`），别提交到仓库。

## 六、通用注意事项（所有项目）

1. **identifier 发布后不可改**（`src-tauri/tauri.conf.json`），否则用户收不到更新。
2. **capabilities 最小权限原则**：只开用到的插件权限，别复制粘贴全量权限。
3. **图标**：替换 `public/meow-mark.svg`，再运行 `npm run tauri -- icon public/meow-mark.svg -o src-tauri/icons` 生成全套打包图标。
4. **包管理器**：本模板统一 npm，CI 用 `npm ci`，新增依赖保持一致。
5. **Rust 冷构建慢**：CI 上 macOS 约 114s、Windows 约 248s，首次编译要有预期；日常 `tauri dev` 有热更新，无感。
